# insai

Insai's tools for coding agents.

Today this package installs [`nexus-workbench`](https://pypi.org/project/nexus-workbench/):
the command line, MCP server and skills that connect Claude Code and Codex to Insai
Workbench, plus local tools for EDF files. It adds the `insai` command, which does exactly
what `nexus-workbench` does.

```
uvx insai setup
```

Everything else, including docs, is in
[nexus-workbench](https://github.com/Insai/nexus-workbench).

For research use only. Not for clinical decision-making.
